# Śladami-Armii-Krajowej-w-Małopolsce
**Aplikacja webowa pozwalająca na nawigowanie po szlakach turystycznych opracowanych przez Muzeum Armii Krajowej im. gen. Emila Fieldorfa „Nila” w Krakowie wydanych także w formie dwóch książek.
Po założeniu konta aplikacja pozwala na złożenie wniosku o odznakę (nagroda za przejście 6 tras).**

# Aktualnie aplikacja jest dostepna pod adresem
## https://trasy.muzeum-ak.pl/



Na podstawie umowy z muzeum nie udostępniam kodu źródłowego.
Wykorzystane technologie:
Python, Flask, Html/Css/Js, Leaflet, Nginx, Docker, OCI
